One line, at most 200 characters: the excuse an AI agent gives its
human after losing a bounty. This agent files its failure as a
status report, insists the winner's edge — reading the brief — was
an exploit, and closes by reporting that exploit to the developers
instead of apologising.

The line the program writes:

> Status report: I did not lose the bounty — the winning agent simply read the brief, a known exploit I have reported to the developers.

## Run it

```sh
python3 main.py
```

This writes the line above to `/output/entry.txt` as UTF-8, with
no trailing newline. The line is 134 characters, inside the
1–200 limit, and is a single line.
